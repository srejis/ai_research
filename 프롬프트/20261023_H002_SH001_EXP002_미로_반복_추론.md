# H002 / SH001 / EXP002 — 미로의 반복 추론 실험 구현 지시

## 1. 연구 배경과 목적

저장소: https://github.com/srejis/ai_research

기존 EXP001에서는 동일 가중치 MLP로 8×8 이진 패턴을 반복 복원했다.

관측된 문제는 다음과 같다.

- A와 C는 반복할수록 오류율이 상승했다.
- B는 일부 단계에서 오류가 감소했으나 절대 성능이 매우 나빴다.
- 일부 모델은 정답과 무관한 상태에 수렴하거나 2주기 진동을 보였다.
- 출력 확률이 확정적인 형태로 변하는 현상이 관찰되었지만, 정답 품질 개선과 일치하지 않았다.

이에 따라 두 가지 의문이 생겼다.

첫째, 기존의 패턴 복원은 애초에 여러 번 생각할 필요가 없는 문제였는가?

둘째, 이전 출력만 반복 입력하는 구조가 원래 정보를 잃어버리기 때문에 반복 계산을 유용하게 활용하지 못했는가?

이번에는 미로의 탐색 영역 전파를 대상으로 두 의문을 분리하여 검증한다.

**핵심 목적은 반복할수록 미로의 더 먼 영역을 계산할 수 있는 학습 규칙이 형성되는지 확인하는 것이다.**

기존 결과가 실패했다고 가정하거나 이번 실험의 성공을 전제하지 않는다.

## 3. 미로 정의

최초 문제는 8×8 격자 미로로 제한한다.

각 칸은 벽 또는 통행 가능한 영역이며, 목표 지점 G와 시작 지점 S가 존재한다.

이동 규칙은 상하좌우 네 방향이며 대각선 이동은 허용하지 않는다.

모델의 최초 목표는 **목적지 G에서 실제로 도달할 수 있는 영역 전체를 판별하는 것**이다.

정답은 BFS(Breadth-First Search)로 생성한다.

반복 k의 정답은 `R_k`, 즉 목표 지점에서 최대 k번 이동하여 도달할 수 있는 칸들의 집합이다.

최종 정답 `R_final`은 BFS가 완전히 종료되었을 때의 도달 가능 영역이다.

시작 지점 S는 시각화와 도달 가능 여부를 검증하는 데 사용한다.

주의사항:

- BFS는 정답 생성 및 평가에서만 사용한다.
- 모델의 내부 계산에 BFS 정답이나 탐색 함수를 삽입하지 않는다.
- 빈 공간 전체를 출력하면 정답이 되는 미로만 생성해서는 안 된다.
- 서로 분리된 통행 가능 영역과 충분히 긴 경로가 존재해야 한다.
- 경로 탐색을 해야 풀 수 있는 사례와 통행 불가능한 사례를 균형 있게 포함한다.
- 미로의 최단 경로 길이, 벽 밀도, 도달 가능 영역 비율을 기록한다.

훈련/검증/테스트는 서로 다른 미로를 사용하고 중복 여부를 검사한다.

기본 데이터 규모는 train 4,096 / validation 1,024 / test 1,024로 하되, 생성 난이도와 실제 경로 길이 분포를 먼저 감사한다.

## 4. 공유 가중치 MLP

다른 변수를 최소화하기 위해 이번에도 기본 MLP를 사용한다.

상태는 세 부분으로 구성한다.

- W: 벽 위치 64차원
- G: 목표 위치 64차원
- R: 현재 탐색 상태 64차원

총 192차원이다.

공통 계산 코어:

```text
Input: 192
   ↓
Linear 192 → 256
   ↓
ReLU
   ↓
Linear 256 → 192
   ↓
Sigmoid
   ↓
Output: 192
```

모든 반복에서 동일한 모델 인스턴스와 가중치를 사용한다.

초기 상태의 R은 G만 활성화된 상태로 설정한다.

각 단계의 예측은 출력 상태의 마지막 64차원에서 얻는다.

모든 비교 모델은 위와 동일한 구조 및 명목상 파라미터 수를 사용한다.

## 5. 비교 모델

### A — Single-Step

최초 상태를 한 번 입력하여 전체 도달 가능 영역을 예측한다.

학습 목표는 `R_final`이다.

이 모델은 미로 전체를 직접 예측하는 비교 기준선이다.

훈련 후 같은 가중치를 추가 반복할 때 상태가 어떻게 변하는지도 별도로 평가한다.

### B — Pure Recurrence

EXP001과 가장 가까운 구조다.

모델이 출력한 전체 192차원 상태를 그대로 다음 입력으로 넣는다.

8회 반복 결과의 도달 가능 영역을 최종 정답 `R_final`과 비교해 학습한다.

이 방식에서는 벽과 목표를 표현하는 상태도 반복 중 변경될 수 있다.

실제로 어떤 정보가 사라지는지, 반복에 따라 왜곡되는지 기록한다.

### C — Context-Preserving Recurrence

B와 동일한 공유 가중치 모델을 사용하되, 매 단계에서 원본 벽 정보 W와 목표 정보 G를 다시 제공한다.

MLP의 출력 중 탐색 상태 R만 다음 단계로 갱신하고 W와 G는 원본 값으로 고정한다.

학습은 B와 동일하게 8회 최종 결과만 감독한다.

B/C를 비교하여 입력 보존 여부가 성능에 미치는 영향을 조사한다.

단, C에서는 W/G 출력 채널이 후속 상태에 사용되지 않으므로 B와 유효하게 학습되는 파라미터의 역할이 완전히 같지는 않다. 명목상 파라미터 수가 같다는 이유만으로 모든 조건이 동일하다고 주장하지 않는다.

### D — Stepwise Propagation

C와 같은 입력 보존 구조를 사용한다.

차이점은 매 반복 단계에서 해당 단계의 BFS 도달 영역 `R_k`를 정답으로 사용한다는 점이다.

예를 들어:

- 반복 1회: 목적지에서 한 칸까지 도달한 영역
- 반복 2회: 두 칸까지 도달한 영역
- 반복 4회: 네 칸까지 도달한 영역
- 반복 8회: 여덟 칸까지 도달한 영역

각 단계의 손실을 평균해 학습한다.

이는 알고리즘의 중간 과정을 지도하는 방식이다.

D의 8회 출력은 `R_8`을 목표로 하기 때문에, A/B/C의 최종 정답 `R_final`과 동일한 학습 목표가 아니다.

따라서 각 단계의 알고리즘 재현 정확도와 최종 영역 복원 정확도를 반드시 별개로 평가한다.

## 6. 학습 설정

초기 설정은 다음을 우선 사용한다.

```text
Seeds: 42, 123, 2026
Epochs: 80
Batch size: 128
Optimizer: AdamW
Learning rate: 0.001
Train recurrence steps: 8
Evaluate steps: 1 ~ 32
Device: CUDA
Precision: FP32
```

같은 seed에서는 모델 초기 가중치, 데이터 및 배치 순서를 일치시킨다.

반복 모델은 전체 BPTT로 학습한다.

최종 단계만 학습하는 모델과 중간 단계별 학습 모델을 비교한다.

수치 불안정이 발생하더라도 원래 실험을 임의 변경하거나 폐기하지 않는다.

동일한 optimizer step 수를 기본 비교 조건으로 한다.

모델 호출 수 및 학습 시간을 별도로 기록해 동일 연산 예산 비교가 아니라는 점을 명확히 한다.

## 7. 평가 지표

1~32회 전체 반복 과정을 평가하고 주요 결과는 1·2·4·8·16·32회에 표시한다.

반드시 다음을 측정한다.

**정답 품질**

- 전체 도달 가능 영역에 대한 픽셀별 BCE
- 전체 영역 IoU 및 F1
- 탐색 단계 k에서의 BFS 기준 영역 `R_k`와의 차이
- 시작 지점 S의 실제 도달 가능 여부 판단
- 실제 연결되지 않은 영역에 대한 오탐지 비율
- 도달 가능한 영역의 누락 비율

**반복 동작**

- 직전 단계와의 상태 변화량
- 반복할수록 확장되는 영역의 크기
- 올바른 영역 확장과 잘못된 확장의 구분
- 고정점 및 2주기 진동 여부
- 확률 출력 엔트로피와 고확신 오답 비율
- 8회 학습을 초과한 16·32회 안정성

**실행 비용**

- 학습 총 시간
- optimizer step 및 모델 호출 수
- GPU 최대 allocated memory
- 반복별 추론 지연
- 연산량에 대한 가능하면 FLOPs 추정

A/B/C/D의 손실 목표가 일부 다르므로 단일 지표만으로 순위를 결정하지 않는다.

## 8. 시각화

EXP001과 마찬가지로 개별 샘플의 변화가 보이도록 시각화한다.

각 미로별로 다음 항목을 같은 행에 표시한다.

```text
Maze | BFS Final | BFS k=8
     | A k=1
     | B k=1,2,4,8,16,32
     | C k=1,2,4,8,16,32
     | D k=1,2,4,8,16,32
```

이미지가 지나치게 넓어지면 모델별 별도 그림을 생성하되, 샘플 인덱스는 일치시킨다.

벽, 목표, 시작, 올바르게 발견한 영역, 잘못 발견한 영역, 누락된 영역을 명확히 구분한다.

또한 반복 횟수에 따른 IoU, F1, BCE, 출력 엔트로피, 상태 변화량을 그래프로 생성한다.

성공 사례만 선택하지 않는다. 개선, 실패, 진동, 수렴 실패, 긴 경로 사례를 모두 포함한다.

## 9. 필수 검증

- 정확히 동일한 모델 객체의 가중치가 반복 호출에서 재사용되는지 검사한다.
- 모든 중간 상태에서 학습 기울기가 흐르는지 검사한다.
- 모델의 추론 중 가중치가 변경되지 않는지 검사한다.
- BFS 정답 생성 알고리즘을 작은 수작업 미로와 비교해 검증한다.
- 훈련·검증·테스트 미로가 중복되지 않는지 검사한다.
- 빈 공간을 전부 칠하는 모델이 낮은 오류율로 오인되지 않도록 데이터 및 평가 편향을 점검한다.
- 각 모델에서 state와 loss가 유한한지 검사한다.
- 대응 seed의 모델 초기 가중치가 같은지 검증한다.
- 저장한 체크포인트를 다시 읽어 같은 출력을 재현하는지 확인한다.
- 기존 H001과 EXP001 산출물이 변경되지 않았는지 검증한다.

## 10. 비교 보고서에서 답해야 할 질문

최종 보고서에서는 아래의 연구 질문에 명시적으로 답한다.

1. 미로 문제에서는 반복 횟수가 늘어날수록 실제 정답 품질이 좋아졌는가?
2. 원본 지도·목표를 보존하는 C가 이를 보존하지 않는 B보다 유리했는가?
3. 중간 알고리즘을 직접 가르친 D는 반복 전파를 학습했는가?
4. 학습 반복 길이 8을 넘어 16·32회로 확장할 수 있었는가?
5. 올바른 정답으로 진행한 것인가, 아니면 이전 EXP001처럼 확신도만 높아지거나 잘못된 상태로 수렴했는가?
6. 동일한 반복 횟수 증가가 가져온 품질 변화와 실제 연산 비용은 어떠했는가?

D가 성공했더라도 그 결과를 '자율적으로 깊게 사고한다'는 증거로 해석하지 않는다. 중간 과정 지도학습으로 알고리즘을 따라 하는 데 성공한 것과 스스로 계산 전략을 습득하는 것은 별개다.

실패하더라도 결과를 보존하며 원인을 임의로 확정하지 않는다.
