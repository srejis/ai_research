# AI 연구 프로젝트 디렉터리 구조 재정비 — 사용자 지시문

## 작업 목적

현재 연구 프로젝트 루트 폴더에 첫 번째 MLP 기준 모델 학습에 사용한 코드와 체크포인트, 결과 파일들이 직접 생성되어 있다.

이 프로젝트는 앞으로 여러 가설과 실험을 관리할 연구 저장소이므로, 각 가설과 실험의 파일들이 서로 섞이지 않도록 디렉터리 구조를 개편한다.

이번 작업은 기존 코드의 실험 알고리즘을 수정하는 것이 아니라 **연구 프로젝트의 디렉터리 구조를 정리하고 기존 학습 결과를 보존하는 작업**이다.

## 1. 계층 구조

- H: 전체 가설 또는 상위 연구 주제
- SH: 전체 가설에 속한 부분 가설 또는 세부 연구 질문
- EXP: 실제로 실행하는 개별 실험

**H001 — Dynamic Network**: 신경망의 구조가 동적으로 변할 때 기존 학습 상태의 유지와 적응 가능성을 연구한다.

**SH001 — Node Growth**: 새로운 뉴런 추가가 기존 가중치에 미치는 영향을 연구한다.

**EXP001 — Baseline MLP**: 기준 MLP 모델을 학습하고 에포크별 가중치를 저장한 실험이다. 학습은 이미 실행되었으며 실제 결과는 기존 산출물을 확인해야 한다.

**EXP002 — Single Node Growth**: 중간 학습 단계 및 학습 완료 단계에서 뉴런 하나를 추가하고, 기존 가중치의 변화를 비교하는 후속 실험이다.

## 2. 디렉터리 구성

아직 진행하지 않은 EXP002는 폴더만 준비하거나 향후 실행 시 생성해도 된다.

## 3. 기존 파일 이전

우선 현재 프로젝트 디렉터리의 실제 파일 구조와 각 파일의 역할을 확인한다. 기준 MLP 학습과 관련된 파일들을 EXP001_baseline_mlp 디렉터리로 이동한다.

1. 기존 학습 결과와 체크포인트를 삭제하거나 덮어쓰지 않는다.
2. 기존 모델을 새로 학습하지 않는다.
3. 모델 가중치와 옵티마이저 상태를 그대로 보존한다.
4. 원본 체크포인트의 epoch 번호 및 실험 설정을 유지한다.
5. 데이터셋처럼 여러 실험에서 공유할 수 있는 자원은 중복 복사하지 않도록 한다.
6. 실험 관련 여부가 불분명한 파일은 임의로 이동하지 않고 별도로 보고한다.
7. 기존 디렉터리 구조에 이미 별도로 관리 중인 파일이 있다면 그대로 유지한다.

파일 이동 전 목록을 기록하고, 이동 후 파일 수와 크기 및 주요 체크포인트의 무결성을 확인한다.

## 4. 실행 경로 수정

상대 경로 및 절대 경로 참조, 학습 데이터 경로, 체크포인트 저장 및 불러오기 경로, 결과 그래프 저장 경로, 설정 파일 경로, Python import 경로를 점검한다.

기존 Anaconda 환경 D:\anaconda3\envs\research를 그대로 사용한다. 가상환경은 연구 프로젝트 폴더 안으로 이동하지 않는다. 경로를 반복 하드코딩하지 않고 각 실험 디렉터리 기준으로 일관되게 해결한다.

## 5. 기준 모델 복원 검증

- 학습 완료 체크포인트 로드 성공
- 중간 에포크 체크포인트 로드 성공
- 모델 구조 및 가중치 일치
- 기존 기록의 검증 정확도와 복원 모델의 검증 결과 일치 여부

복원에 실패하면 추가 실험을 진행하지 않는다. 재평가 결과가 원래 기록과 다르면 원인을 조사하고 원본 기록은 변경하지 않는다.

## 6. 실험 간 연결 방식

EXP002는 EXP001의 모델을 출발점으로 사용한다. 체크포인트를 불필요하게 복제하지 말고 설정 파일에서 경로를 참조한다. 각 실험은 자신의 결과와 새로운 체크포인트만 저장한다. 조건 변경 시에도 원본 기준 모델을 계속 보존한다.

## 7. 문서 및 관리 규칙

루트 README에 전체 연구 목록, H001 README에 목적과 부분 가설, SH001 README에 연구 질문과 실험 목록을 정리한다. 각 EXP README에는 목적, 설정, 실행 방법, 기준 모델과 출처, 결과 파일, 진행 상태와 결과 요약을 남긴다. 확인되지 않은 실험 결과를 작성하지 않는다. 신규 연구도 동일한 H → SH → EXP 구조를 따른다.

## 8. 작업 완료 기준

1. 기준 MLP 파일들이 EXP001로 정리됨.
2. 루트에는 연구별 폴더와 공통 관리 파일만 남음.
3. 기존 체크포인트와 학습 결과가 온전히 보존됨.
4. 변경된 경로에서 기존 학습 결과를 읽고 분석할 수 있음.
5. EXP002가 EXP001 체크포인트를 참조할 수 있음.
6. 각 연구의 README와 실행 경로가 정리됨.

**추가 학습이나 노드 추가 실험을 실행하지 않는다. 기존 결과 정리와 복원 가능성 검증까지만 수행한다.**
