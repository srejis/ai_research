# H001 / SH001 — 연구 폴더 재정비 및 EXP002 구현·실행 지시서

## 1. 작업 배경과 목적

현재 AI 연구 프로젝트에서 첫 번째 기준 MLP 모델(EXP001)의 학습이 완료되었다.

그러나 기준 모델의 코드, 학습 결과 및 체크포인트가 연구 프로젝트 루트에 직접 생성되었다.

앞으로 여러 전체 가설과 부분 가설, 실험이 추가될 예정이므로 디렉터리 구조를 먼저 재정비해야 한다.

또한 기존 기준 모델을 활용하여 **EXP002 — 뉴런 1개 추가 시점에 따른 기존 가중치 변화 실험**을 진행한다.

이번 작업은 다음 순서로 수행한다.

1. 기존 파일 조사 및 디렉터리 재정비
2. EXP001 기준 모델 복원 및 정상 작동 검증
3. EXP002 구현 및 학습 실행
4. 가중치 변화 분석과 결과 보고

기존 기준 모델을 다시 학습하지 않는다. 저장된 체크포인트를 재사용한다.

# Part A. EXP001 검증

## 4. 기준 모델 확인

기존 EXP001의 설정 파일과 학습 결과를 확인한다.

기존에 계획한 기본 모델은 다음과 같다.

`784 → 256 → 128 → 10`

그러나 실제 구현이 이와 다르다면 **실제 학습에 사용된 모델 구조를 기준으로 판단**한다. 기존 체크포인트에 맞추기 위해 훈련된 가중치를 임의로 변환하지 않는다.

학습 데이터는 MNIST이며, 학습 완료 조건은 검증 정확도 95% 최초 달성이었다.

학습 로그를 읽어 실제 완료 에포크를 `E_complete`로 확정한다.

중간 에포크는 다음과 같이 계산한다.

`E_mid = floor(E_complete / 2)`

두 에포크에 대응하는 체크포인트를 확인한다.

### 검증해야 할 내용

- 학습 로그에 기록된 완료 에포크 확인
- 최초 95% 달성 여부 확인
- 중간 모델 체크포인트 존재 확인
- 최종 모델 체크포인트 존재 확인
- 두 체크포인트의 모델 구조와 가중치 복원 성공
- 복원 후 검증 정확도의 재현 여부
- 데이터 분할 및 전처리 일치 여부

기존 학습 결과가 예상과 달라도 자동으로 모델을 재학습하지 않는다.

실험에 필요한 체크포인트가 누락되었거나 복원에 실패한다면 EXP002 진행을 중단하고 원인과 필요한 조치를 보고한다.

# Part B. EXP002 — 뉴런 추가 실험

## 5. 연구 목적

이번 실험에서는 기존에 학습한 신경망에 **뉴런 하나를 추가하는 행위가 기존 가중치의 변화에 어떤 영향을 미치는지** 관찰한다.

특히 다음을 비교한다.

- 학습 중간에 뉴런을 추가한 경우
- 학습 완료 후 뉴런을 추가한 경우
- 동일한 시점에 뉴런을 추가하지 않고 계속 학습한 경우

핵심 측정 대상은 기존 가중치의 변화다.

최종 정확도 향상이나 새로운 구조의 우수성을 입증하는 것이 주목적은 아니다.

## 6. 실험군 구성

동일한 EXP001 기준 모델의 체크포인트를 이용하여 네 가지 실험군을 생성한다.

| 실험군 | 시작 시점 | 구조 | 목적 |
|---|---|---|---|
| B0 | E_mid | 기존 MLP | 중간 시점 무확장 대조군 |
| B | E_mid | 뉴런 1개 추가 | 중간 시점 확장 |
| C0 | E_complete | 기존 MLP | 완료 시점 무확장 대조군 |
| C | E_complete | 뉴런 1개 추가 | 완료 시점 확장 |

B와 B0는 같은 체크포인트로부터 시작한다.

C와 C0도 같은 체크포인트로부터 시작한다.

이를 통해 구조 변경에 따른 차이를 대응 대조군과 비교할 수 있도록 한다.

## 7. 뉴런 추가 방식

기준 모델이 기존 설계대로 구현되었다면 첫 번째 은닉층을 확장한다.

기존:

`784 → 256 → 128 → 10`

확장:

`784 → 257 → 128 → 10`

**뉴런은 정확히 1개만 추가한다.**

기존 첫 번째 은닉층의 256개 뉴런과 가중치는 그대로 유지한다.

새로 생성한 뉴런의 입력 연결 가중치와 편향은 고정된 시드를 사용해 초기화한다.

두 번째 은닉층으로 향하는 새 뉴런의 출력 연결은 0으로 초기화한다.

이렇게 하면 뉴런을 추가한 직후에는 기존 모델의 출력이 수치 오차 범위에서 유지된다.

단, 새 출력 연결이 0이므로 첫 번째 업데이트에서 새 뉴런 입력 가중치의 그래디언트가 0일 수 있다. 이 현상을 별도로 기록한다.

기존 가중치와 새로 생성된 가중치를 구별할 수 있도록 파라미터 인덱스 매핑을 보존한다.

### 구조 변경 직후 검증

기존 모델과 확장 모델에 동일한 검증 입력을 전달한다.

추가 학습을 시작하기 전에 출력 logits의 차이를 측정한다.

출력에 예기치 않은 변화가 발생했다면 해당 실험군은 학습을 진행하지 않고 원인을 조사한다.

---

## 8. 추가 학습 조건

중간 시점부터 기준 모델 완료 시점까지의 학습 에포크 수를 다음과 같이 정의한다.

`K = E_complete - E_mid`

모든 분기에서 이 K만큼 추가 학습한다.

- B0: E_mid부터 K 에포크
- B: E_mid부터 K 에포크
- C0: E_complete부터 K 에포크
- C: E_complete부터 K 에포크

예를 들어 E_complete가 18이면 E_mid는 9이고 K는 9다.

분기 실험에서는 95%에 도달했다고 다시 조기 종료하지 않는다. 정해진 구간의 가중치 변화를 관찰해야 하기 때문이다.

### 학습 조건 통제

각 대응 실험군은 동일한 학습률, 배치 크기, 데이터셋, 전처리, 추가 학습 스텝을 사용한다.

데이터 셔플 순서도 대응 실험군 사이에서 같게 유지한다.

분기 시 기존 옵티마이저 상태를 그대로 이식하는 복잡성을 배제하기 위해, 첫 실험에서는 네 분기 모두 동일한 설정의 새로운 AdamW 옵티마이저를 생성한다.

이때 비교 결과는 **옵티마이저를 새로 시작한 조건**에 대한 결과라는 점을 반드시 기록한다.

원래 기준 모델의 옵티마이저 상태를 유지하며 확장하는 실험은 별도로 수행할 수 있도록 코드를 분리한다.

# Part C. 가중치 기록 및 분석

## 9. 체크포인트 기록 시점

각 실험군의 가중치를 다음 시점에 저장한다.

1. 분기 시작 직전
2. 뉴런 추가 직후, 추가 학습 이전
3. 첫 번째 optimizer step 직후
4. 이후 매 에포크 종료 시점

특히 첫 번째 업데이트 직후 가중치 변화는 별도로 기록한다.

모든 체크포인트는 대응 실험군 디렉터리에 저장한다.

원래 EXP001의 체크포인트는 절대로 변경하지 않는다.

## 10. 기존 가중치 변화 분석

분석 시 새로 추가된 파라미터와 원래부터 존재하던 파라미터를 반드시 구분한다.

기존 가중치는 분기가 시작된 시점의 동일한 가중치와 비교한다.

각 레이어에 대해 다음을 계산한다.

**절대 변화량**

`ΔW = W_current - W_start`

**상대 변화량**

`Relative Change = ||ΔW||₂ / (||W_start||₂ + ε)`

각 텐서의 변화량과 함께 평균 절대 변화량, 최대 변화량, 변화 분포도 기록한다.

특히 다음을 관찰한다.

- 첫 번째 은닉층 기존 가중치의 변화
- 두 번째 은닉층 기존 가중치의 변화
- 출력층 기존 가중치의 변화
- 새 뉴런 입력 및 출력 가중치의 변화
- 레이어별 변화 크기와 방향의 차이

### 확장하지 않은 모델과 비교

B와 B0, C와 C0를 비교한다.

같은 출발 체크포인트의 기존 가중치에 대해 다음을 계산한다.

`ΔW_growth - ΔW_control`

이를 통해 뉴런을 추가한 실험군에서 기존 가중치의 학습 궤적이 얼마나 달라졌는지 측정한다.

필요하면 업데이트 벡터의 코사인 유사도를 이용해 방향 차이도 측정한다.

실험군마다 기존 가중치의 동일한 좌표를 대응시켜 비교해야 하며, 새 뉴런의 파라미터를 기존 텐서의 변화량에 포함하지 않는다.

## 11. 정확도 및 손실 기록

모든 실험군에 대해 매 에포크 다음 지표를 저장한다.

- Train loss
- Validation loss
- Train accuracy
- Validation accuracy
- 기존 가중치 변화량
- 새 뉴런의 가중치 변화량

기존 가중치의 변화가 실제 모델의 성능 변화와 어떤 관계에 있는지 함께 관찰한다.

가중치 변화량이 크다고 반드시 모델의 성능이 향상되었다고 해석하지 않는다.

추가 실험이 필요한 항목은 별도로 제시한다.

## 14. 완료 조건

이번 작업은 아래 조건을 모두 만족하면 완료한다.

- 기존 EXP001 파일을 별도 실험 폴더로 정리했다.
- 기존 모델과 체크포인트가 훼손되지 않았다.
- EXP001에서 실제 중간·최종 체크포인트를 확인했다.
- EXP002에서 뉴런을 정확히 1개 추가했다.
- B0, B, C0, C의 학습이 정상적으로 종료됐다.
- 모든 실험군의 가중치 및 성능 기록이 저장됐다.
- 기존 가중치 변화량을 실험군별로 비교할 수 있다.
- 분석 그래프와 연구 보고서가 생성됐다.
- EXP001을 다시 학습하지 않고 EXP002를 재현할 수 있다.

기존 기준 모델의 복원과 검증이 정상적으로 완료되면 별도 승인 단계 없이 EXP002까지 이어서 실행한다.
