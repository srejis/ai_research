# H002 / SH001 / EXP003 — 복잡도 증가에 따른 반복 추론 및 사고 기록 통합 효과 검증

## 1. 연구 목적

저장소: https://github.com/srejis/ai_research

이번 실험은 기존 공유 가중치 반복 모델에 **별도의 비순환 출력 MLP를 추가하고, 반복 과정의 기록을 통합하는 방식이 복잡한 문제에서 효과적인지** 확인한다.

사용자가 제안한 구조는 다음과 같다.

1. 반복 추론 MLP는 원본 문제와 이전 내부 상태를 받아 계속 새로운 중간 결과를 생성한다.
2. 각 반복의 중간 결과를 기록한다.
3. 별도의 출력 MLP가 원본 문제와 과거 중간 결과들을 결합해 최종 판단을 만든다.
4. 출력 MLP 자체는 반복하지 않으며, 그 출력은 반복 추론 MLP에 되돌려 넣지 않는다.

**이번 목적은 반복 계산이 반드시 필요한 문제를 만드는 것이 아니다.**

일반 MLP도 풀 수 있는 완전 관측 문제를 사용하되, 문제의 복잡도가 높아질 때 두 구조의 성능 격차가 어떻게 달라지는지를 측정한다.

부분 관측 기억 문제, 열쇠를 기억해야만 풀 수 있는 문제, 실시간 외부 입력 갱신 문제는 이번 범위에서 제외한다.

### 핵심 연구 질문

- 문제 복잡도가 높아질수록 일반 MLP와 공유 가중치 반복 모델의 성능 차이는 어떻게 변하는가?
- 반복 모델에 별도의 출력 MLP를 추가하면 실제로 성능이 개선되는가?
- 출력 MLP에 마지막 상태뿐 아니라 과거 전체 중간 결과를 주면 추가적인 이익이 있는가?
- 과거 기록의 도움과 단순한 파라미터 수 증가 효과를 구분할 수 있는가?
- 성능이 개선되더라도 같은 학습·추론 비용을 기준으로 이익이 유지되는가?

## 4. 학습 문제 — 복잡도별 미로

기존과 동일하게 BFS로 정답을 검증할 수 있는 **완전 관측 미로의 도달 가능 영역 문제**를 사용한다.

단순히 벽의 개수를 높이는 것이 아니라 다양한 복잡도 조건을 도입한다.

### 난이도 요소

- 실제 미로 크기: 8×8, 12×12, 16×16
- 목적지에서 가장 먼 도달 가능 지점까지의 BFS 거리
- 갈림길과 분기 수
- 막다른 길 수
- 우회 경로의 길이
- 분리된 통행 가능 영역의 개수와 비율
- 벽 밀도
- 지도 생성 계열: 랜덤 장애물 및 통로 기반 미로 등

기존과 마찬가지로 이동은 상·하·좌·우 네 방향만 허용한다.

모델에는 미로 벽과 목적지의 전체 정보를 제공한다.

BFS는 정답 생성, 난이도 판정, 검증에서만 사용한다. 모델 추론에 탐색 알고리즘을 직접 주입해서는 안 된다.

### 입력 차원 통일

8×8, 12×12, 16×16 미로를 동일한 모델에 입력할 수 있도록 16×16 크기의 공통 캔버스를 사용한다.

각 샘플의 입력은 다음을 포함한다.

- V: 실제 유효 셀을 나타내는 마스크
- W: 벽 지도
- G: 목적지 위치

총 기본 입력 차원은 `3 × 256 = 768`이다.

반복 추론 상태 R은 256차원이다.

작은 미로는 공통 캔버스에 배치하되, 패딩 영역은 V로 명확히 구분한다.

패딩을 실제 벽 또는 통행 가능한 공간으로 해석해서는 안 된다.

가능하면 작은 미로의 캔버스 내 위치와 방향도 다양하게 배치하여 고정 좌표 패턴만 외우는 일을 줄인다.

손실과 IoU/F1은 유효 셀 영역에 한정해 계산한다.

### 난이도 구분

우선 아래 BFS 거리 구간을 기준 후보로 사용한다.

- Easy: 4~8
- Medium: 9~16
- Hard: 17~32
- Extreme: 33 이상

단, 실제 데이터 생성 가능성을 먼저 검사한다.

작은 미로에서는 특정 구간이 생성되지 않을 수 있으므로 존재하지 않는 난이도 구간을 억지로 채우거나 생성 조건을 조용히 완화하지 않는다.

각 결과는 **미로 크기와 BFS 거리 난이도를 별개의 축으로** 보고한다. 크기가 크다는 이유만으로 어렵다고 판단하지 않는다.

또한 분기 수·막다른 길·분리 영역에 따른 세부 비교도 수행한다.

### 데이터 분할

기본 목표 규모:

- 학습: 미로 크기별 4,096개
- 검증: 크기별 1,024개
- 테스트: 크기별 1,024개

총 학습 12,288개, 검증 3,072개, 테스트 3,072개를 기본값으로 설정한다.

생성 가능성과 난이도별 분포를 먼저 감사하고, 필요하면 생성 실패 원인을 기록한다.

서로 회전·반사한 지도가 분할 사이에 섞이지 않도록 기존 EXP002의 중복 검증 정책을 재사용한다.

미로 생성 계열과 난이도 구간의 분포도 기록한다.

## 5. 반복 추론 코어

기존 연구 방향을 유지한다.

반복 코어는 원본 문제 정보를 매번 보존하면서 직전 추론 상태 R을 갱신한다.

\[
R_{k+1}=F_\theta(V,W,G,R_k)
\]

초기 상태는 `R0=G`다.

최초 모델 후보:

```text
입력:
 V 256
 W 256
 G 256
 R 256
 ──────────
 1024차원
    ↓
 Linear 1024 → 256
    ↓
 ReLU
    ↓
 Linear 256 → 256
    ↓
 Sigmoid
    ↓
 다음 R: 256차원
```

모든 반복에서 동일한 코어 가중치를 재사용한다.

R을 갱신하더라도 원본 V/W/G는 절대로 변경하지 않는다.

기본 반복 학습 길이는 8회다.

먼저 BFS의 단계별 R1~R8을 지도하여 반복 중간 상태를 만들 수 있도록 학습한다.

이 과정은 기존 EXP002의 D와 비슷한 목적을 가지지만 미로 크기와 난이도 범위가 달라졌으므로 별도 실험으로 기록한다.

정답 R_k를 반복 코어의 다음 입력에 직접 넣는 teacher forcing을 기본값으로 사용하지 않는다. 실제로 모델이 생성한 R_k를 다음 단계에 사용해야 한다.

## 6. 출력 MLP 구조

**핵심 신규 요소다.**

반복 코어가 만든 R1~R8을 기록해 두었다가, 최종 출력 MLP에서 사용한다.

### D — 전체 사고 기록 통합

입력:

```text
원본 문제 V/W/G: 768차원
R1: 256
R2: 256
R3: 256
R4: 256
R5: 256
R6: 256
R7: 256
R8: 256

합계: 2816차원
        ↓
      출력 MLP
        ↓
최종 도달 영역: 256차원
```

출력 MLP의 기본 구조는 `2816 → 256 → 256`으로 설정한다.

중간 ReLU, 최종 logits 출력 구조를 사용하고, 학습에는 BCEWithLogitsLoss를 적용한다.

평가 시 sigmoid를 적용해 확률과 이진화된 결과를 얻는다.

**출력 MLP는 한 번만 실행한다.** 출력 MLP가 계산한 결과를 다시 반복 코어에 넣지 않는다.

최종 감독 목표는 BFS가 계산한 전체 도달 가능 영역 R_final이다.

## 7. 비교 모델과 공정성

네 가지 기본 방식과 필수 대조군을 구분한다.

### A — 단일 MLP

원본 문제 V/W/G를 한 번 처리하고 R_final을 예측한다.

기존의 일반적인 단일 추론 기준선이다.

기본 규모의 A와 별도로, 반복 코어+출력 헤드의 총 학습 파라미터 규모에 맞춘 대형 A도 준비한다.

단일 모델의 파라미터 수 또는 표현력이 너무 작아서 반복 모델이 유리해지는 상황을 막기 위한 대조군이다.

### B — 반복 코어 + 마지막 결과

공유 가중치 코어를 8회 실행한다.

마지막 결과 R8을 곧바로 최종 예측으로 사용한다.

반복 추론 자체의 효과를 나타내는 기준선이다.

### C — 반복 코어 + 마지막 결과를 사용하는 출력 MLP

B와 동일한 반복 코어를 사용한다.

최종 출력 MLP에는 원본 문제와 마지막 R8을 제공한다.

다만 D와의 정확한 비교를 위해 출력 헤드의 입력 차원을 동일하게 유지한다.

즉, 기록 슬롯 8개에 모두 같은 R8을 복제한다.

```text
[V,W,G,R8,R8,R8,R8,R8,R8,R8,R8]
```

이 구조는 D와 출력 MLP의 입력 길이, 가중치 수, 기본 연산량을 동일하게 만든다.

### D — 반복 코어 + 전체 중간 기록을 사용하는 출력 MLP

C와 같은 출력 MLP 구조를 사용한다.

차이는 실제 기록을 제공한다는 점뿐이다.

```text
[V,W,G,R1,R2,R3,R4,R5,R6,R7,R8]
```

따라서 C와 D의 성능 차이를 통해 과거 기록의 추가 정보가 유용한지 확인한다.

### E — 문제만 사용하는 출력 MLP

D와 동일한 입력 길이 및 출력 헤드 구조를 갖지만 기록 슬롯을 모두 0으로 채운다.

```text
[V,W,G,0,0,0,0,0,0,0,0]
```

이는 최종 출력 MLP가 미로 원본만 보고 문제를 해결하는 경우를 검증하는 대조군이다.

E는 추론 시 반복 코어를 실행할 필요가 없으므로 실제 추론 비용은 그에 맞게 기록한다.

### 비교 원칙

C/D/E의 출력 MLP 구조와 초기화 방식은 동일하게 유지한다.

특히 C와 D는 **동일한 학습 완료 반복 코어에서 만들어진 상태 기록**을 사용해야 한다.

반복 코어를 먼저 학습한 뒤 동결하고, C/D/E의 출력 MLP만 독립 학습한다.

이렇게 해야 반복 코어의 학습 결과 차이와 출력 기록 통합 효과를 분리할 수 있다.

A는 단일 단계 모델이며, 학습 목표 R_final과 데이터를 동일하게 유지한다.

A 대형 모델의 파라미터 규모, 총 연산량 및 학습 예산을 명시적으로 보고한다.

## 8. 학습 단계

### 1단계 — 데이터 생성·감사

모든 난이도 미로를 생성하고 고정한다.

실제 BFS 거리, 분기 수, 도달 가능한 영역, 오답을 유발할 수 있는 분리 영역 등을 검증한다.

생성된 데이터는 해시와 함께 기록한다.

### 2단계 — 반복 코어 학습

B/C/D에 공통으로 사용할 반복 코어를 학습한다.

8회 반복에 대해 BFS R1~R8을 감독한다.

학습 도중 모든 R값이 생성되도록 하고, 각 단계의 gradient 흐름을 검사한다.

학습을 완료한 후 코어를 동결한다.

### 3단계 — 출력 헤드 학습

동결된 코어가 만든 기록을 사용하여 C/D/E의 출력 MLP를 학습한다.

학습 데이터에서만 출력 MLP의 가중치를 갱신한다.

최종 정답은 모두 R_final이다.

같은 seed에서는 C/D/E의 출력 헤드 초기 가중치와 배치 순서를 가능한 한 일치시킨다.

### 4단계 — 단일 MLP 기준선 학습

A와 대형 A를 동일한 학습·검증·테스트 데이터로 학습한다.

반복 코어와 출력 MLP가 사용한 총 학습 시간 및 optimizer step을 기록한다.

기본 비교 외에 학습 시간 또는 추론 FLOPs 예산을 비슷하게 맞춘 기준선도 마련한다.

### 5단계 — 선택적 추가 실험

1~4단계의 결과를 원본으로 보존한 뒤, 별도 run에서 C와 D의 출력 loss를 반복 코어까지 역전파하는 end-to-end 학습을 비교할 수 있다.

이는 처음부터 섞지 않는다.

코어 동결 실험과 end-to-end 실험은 서로 다른 연구 조건이다.

## 9. 성능 평가

가장 중요한 것은 **문제 복잡도에 따른 성능 변화**다.

다음 성능을 난이도 구간별로 측정한다.

- 최종 도달 가능 영역 IoU
- F1
- BCE
- 전체 미로의 정확한 영역 복원 성공률
- 시작점 도달 가능 여부 정확도
- 도달 영역 누락률
- 연결되지 않은 영역에 대한 오탐률
- 고확신 오답 비율

전체 테스트 평균만 보고하지 않는다.

반드시 미로 크기와 BFS 거리별 성능을 구분한다.

특히 A 대비 D, C 대비 D, E 대비 D의 난이도별 성능 격차를 그래프로 표시한다.

기록 통합이 실제로 복잡한 문제에서 상대적으로 유리해지는지 검증한다.

## 10. 과거 기록 활용 여부 검증

D가 C보다 좋은 결과를 냈더라도 그것만으로 과거 기록을 유의미하게 활용했다고 단정하지 않는다.

다음 검사를 수행한다.

### 기록 제거

D에 R1~R8 대신 R8 복제만 전달한다.

정확도가 얼마나 달라지는지 확인한다.

### 특정 단계 제거

R1, R2, R3 등 특정 단계의 기록을 원래 학습된 D에 입력할 때 제거하거나 다른 값으로 대체한다.

어느 단계의 기록이 결과에 영향을 많이 주는지 측정한다.

### 기록 순서 교란

R1~R8의 순서를 바꿔 전달한다.

시간에 따른 변화 과정을 학습했는지 확인한다.

### 다른 샘플의 기록 대체

문제는 그대로 두고 중간 기록 일부를 다른 미로의 기록으로 바꾼다.

성능 변화로 기록 의존성을 확인한다.

이러한 교란 평가는 분포 밖 입력을 만들 수 있으므로 결과의 변화가 곧 인간이 이해하는 방식으로 기록을 사용했다는 인과적 증거는 아니다. 여러 검사와 기준선을 함께 해석한다.

## 11. 반복 길이와 통합 길이의 한계

기본 출력 MLP는 R1~R8을 연결하므로 **8개 기록을 전제로 하는 구조**다.

이를 그대로 16개 또는 32개 기록 입력으로 바꾸면 입력 차원이 달라져 재학습 없이 사용할 수 없다.

따라서 이번 1차 실험의 기본 비교는 8회 고정으로 수행한다.

16·32회 평가를 추가하는 경우 다음을 명확하게 구분한다.

- 마지막 8개 기록만 사용하는 고정 길이 윈도우
- 최초 8개 기록을 그대로 사용하는 경우
- 16·32개 전체 기록을 수용하는 별도 출력 MLP

이 세 가지는 같은 실험 조건이 아니다.

처음부터 무한 길이 기록이나 장기 메모리를 구현하지 않는다.

## 12. 계산 비용 측정

정확도뿐 아니라 실제 비용도 측정한다.

- 전체 학습 파라미터 수
- 모델별 optimizer step 수
- 반복 코어 호출 수
- 출력 헤드 호출 수
- 코어/출력 헤드/전체 모델 FLOPs
- 총 학습 시간
- 추론 지연
- peak GPU allocated memory
- 기록 저장에 필요한 메모리

RTX 5090에서 CUDA 동기화와 충분한 warm-up을 사용한다.

측정 횟수와 표준편차를 기록한다.

반복 모델과 A의 학습·추론 비용이 다르다는 사실을 반드시 명시한다.

**반복 모델이 더 정확하더라도 계산 비용이 훨씬 크면, 단순히 더 효율적이라고 주장하지 않는다.**

## 13. 시각화

최소한 다음 자료를 생성한다.

1. 난이도별 A/B/C/D/E IoU 비교 그래프
2. 난이도별 완전 해결 성공률 그래프
3. 미로 크기별 성능 비교
4. C 대비 D의 성능 차이 그래프
5. 기록 제거 및 교란에 따른 성능 변화
6. 성능 대비 학습·추론 비용
7. 개별 미로에 대한 중간 R1~R8 시각화
8. 최종 R8, 출력 MLP C, 출력 MLP D, BFS 정답 비교 이미지

마지막 시각화가 특히 중요하다.

가능하면 동일한 미로에서 다음을 보여준다.

```text
원본 미로
BFS 정답

반복 코어:
R1 → R2 → R3 → ... → R8

최종 출력:
B: R8
C: 마지막 R8 + 출력 MLP
D: 전체 과거 기록 + 출력 MLP
E: 문제만 + 출력 MLP
A: 단일 MLP
```

어떤 영역이 통합 후 새로 맞아졌고, 어떤 영역이 오히려 틀렸는지 구별할 수 있어야 한다.

## 14. 검증

기존 저장소의 검증 방식을 유지한다.

- BFS 정답 독립 검증
- 모든 모델의 입력 차원과 출력 차원 확인
- 동일 가중치 반복 호출 검증
- 반복 코어 동결 및 가중치 불변 검증
- C/D/E 출력 MLP 구조 및 초기 가중치 대응 검사
- 출력 헤드에 정답 BFS 중간 결과를 직접 입력하지 않았는지 검사
- 체크포인트 복원 후 결과 재현
