# EXP003 — 축소 MLP의 뉴런 추가에 따른 학습 경로 및 속도 변화 실험

## 1. 연구 배경과 목적

EXP002에서는 첫 은닉층에 뉴런 하나를 추가했을 때 기존 가중치의 학습 궤적이 무확장 대조군과 달라지는 현상을 관찰했다.

그러나 다음 문제가 있었다.

- 기준 MLP가 1에포크 만에 검증 정확도 95%에 도달했다.
- 학습 중간 시점이 0에포크가 되어 실제 학습 중 구조 변경의 영향을 관찰하지 못했다.
- 기존 가중치의 최종 변화량만으로는 학습 방향이 달라졌는지, 학습이 빨라졌는지 판단하기 어려웠다.
- 기존 모델도 추가 학습을 계속하면 당연히 가중치가 변하므로 단순 가중치 변화량은 충분한 평가 기준이 아니다.

EXP003은 이 문제를 해결하기 위한 후속 실험이다.

**핵심 연구 질문은 뉴런 하나를 추가하면 기존 신경망의 학습 방향과 속도가 어떻게 달라지는가이다.**

이번 실험은 하나의 실험으로 관리한다. 기준 모델 학습, 여러 시점의 구조 변경, 대조군 비교는 모두 EXP003 내부의 실험 조건이다.

## 5. 뉴런 추가 시점

기준 학습의 실제 완료 스텝 `S_complete`를 확인한 이후 분기 시점을 결정한다.

우선 학습 진행률 기준으로 다음 시점을 사용한다.

| 분기 | 학습 시점 |
|---|---|
| P25 | 완료 스텝의 25% |
| P50 | 완료 스텝의 50% |
| P75 | 완료 스텝의 75% |
| P100 | 완료 스텝의 100% |

분기 스텝은 `floor(S_complete × 비율)`로 결정한다.

각 분기는 학습이 실제로 한 스텝 이상 진행된 상태여야 한다. 중복되는 분기 시점이 나타나면 이를 억지로 별개의 조건으로 취급하지 말고 관측 구간 부족 문제를 보고한다.

각 분기에서는 동일한 체크포인트로부터 다음 두 모델을 만든다.

- Control: 원래 구조 그대로 학습
- Growth: 뉴런 하나 추가 후 학습

첫 은닉층을 `32 → 33`으로 확장한다.

**하나의 분기에서는 반드시 정확히 하나의 뉴런만 추가한다.**

새 뉴런의 입력 가중치와 편향은 기록 가능한 고정 시드로 초기화한다.

새 뉴런에서 두 번째 은닉층으로 연결되는 출력 가중치는 0으로 초기화하여 삽입 시점에 기존 모델의 출력이 유지되게 한다.

원래 존재하던 모든 가중치는 정확히 복사한다.

## 6. 옵티마이저 상태 보존

EXP002에서는 분기 시 AdamW 상태를 새로 초기화했다.

이번 실험에서는 옵티마이저 초기화의 영향을 줄이기 위해 다음 방식을 사용한다.

- 기존 가중치에 대한 AdamW의 1차·2차 moment와 step 상태를 보존한다.
- 새로 추가된 파라미터에는 새로운 optimizer state를 생성한다.
- 기존 파라미터의 인덱스 및 optimizer state 매핑을 유지한다.
- Control과 Growth가 공통으로 갖는 원래 가중치에서는 같은 optimizer 상태를 출발점으로 사용한다.

구현이 복잡하다면 새 뉴런 경로를 별도 파라미터로 구성하여 기존 Linear 레이어의 원래 파라미터와 AdamW 상태를 변경하지 않는 방법을 사용할 수 있다.

이 경우에도 수학적으로 의도한 `32 → 33` 확장과 동일한 출력 구조를 가져야 한다.

기존 뉴런과 새 뉴런에 대한 weight decay 및 업데이트 규칙을 명시한다.

특히 각 대응 분기의 동일한 추가 학습 스텝끼리 직접 비교한다.

## 8. 핵심 지표 A — 학습 방향 변화

이번 실험에서 가장 중요한 지표다.

동일한 원래 가중치에 대해 매 optimizer step에서 업데이트 벡터를 계산한다.

`ΔW_t = W_(t+1) - W_t`

각 레이어별로 Control과 Growth의 실제 파라미터 업데이트 방향을 비교한다.

`cos(θ_t) = (ΔW_control · ΔW_growth) / (||ΔW_control|| ||ΔW_growth||)`

다음 지표를 기록한다.

- 스텝별 cosine similarity
- 각 레이어의 업데이트 norm
- 업데이트 방향이 크게 달라지는 최초 시점
- 방향 차이가 일시적인지 누적되는지
- 누적 업데이트 벡터의 방향 차이

신규 뉴런의 파라미터는 기존 가중치의 업데이트 벡터 비교에서 제외한다.

업데이트 벡터의 norm이 거의 0인 경우 cosine 값이 불안정해질 수 있으므로 결측 처리 기준을 명시한다.

또한 optimizer의 영향을 구분하기 위해 실제 업데이트 방향뿐 아니라 같은 배치에서 계산한 기존 파라미터의 task-loss gradient 방향도 함께 기록한다.

이를 통해 다음을 구분한다.

1. 손실함수의 그래디언트 방향이 달라졌는가?
2. 실제 optimizer가 적용한 가중치 업데이트 방향이 달라졌는가?

## 9. 핵심 지표 B — 학습 속도

가중치가 빨리 움직이는 것이 아니라, **같은 계산 단계에서 실제로 손실이 얼마나 줄어드는지** 비교한다.

다음을 측정한다.

- 동일 추가 step에서의 train loss
- 동일 추가 step에서의 validation loss
- 동일 추가 step에서의 validation accuracy
- 특정 검증 정확도에 도달하는 데 필요한 추가 step
- 검증 손실의 감소 속도
- 실제 학습 시간
- 가능한 경우 처리한 샘플 수 및 연산량

속도 비교는 두 관점으로 구분한다.

**학습 스텝 효율:** 같은 데이터와 optimizer step 수에서 어느 모델이 더 잘 학습했는가?

**계산 효율:** 같은 시간 또는 비슷한 연산 비용을 사용했을 때 어느 모델의 성능이 더 좋은가?

뉴런을 추가하면 연산량 자체가 달라지기 때문에, 단순히 step 수가 같다는 이유로 계산 비용이 같다고 주장하지 않는다.

## 10. 핵심 지표 C — 학습 경로 이탈

두 모델은 동일한 출발 가중치를 갖는다.

학습이 진행될수록 기존 가중치가 얼마나 멀어지는지 측정한다.

`D_t = ||W_growth,old(t) - W_control(t)||₂`

이를 레이어별로 계산하고, 초기 가중치 norm으로 정규화한 값도 함께 기록한다.

이 지표만으로 학습 성능을 평가하지 않는다.

방향 cosine, 손실 감소 속도와 함께 비교해 해석한다.

## 11. 신규 뉴런의 학습 상태

새 뉴런이 실제로 학습에 참여했는지 확인한다.

다음 내용을 기록한다.

- 신규 입력 가중치 norm
- 신규 출력 가중치 norm
- 입력·출력 gradient norm
- ReLU 활성화 비율
- 신규 뉴런이 다음 레이어의 pre-activation에 기여하는 정도
- 새 뉴런의 task-loss gradient가 처음으로 0이 아니게 되는 시점

새로운 출력 연결을 0으로 시작하므로 첫 역전파에서 입력 가중치의 task-loss gradient가 0일 수 있다.

이 현상이 발생하더라도 곧바로 학습 실패로 판단하지 않는다.

새 뉴런이 이후 업데이트에서 실제로 기능을 획득했는지 확인한다.

**Q5. 가중치 방향의 변화가 성능 변화와 관계있는가?**

방향이 크게 달라졌다고 반드시 좋은 결과가 나온 것은 아닌지 검토한다.
