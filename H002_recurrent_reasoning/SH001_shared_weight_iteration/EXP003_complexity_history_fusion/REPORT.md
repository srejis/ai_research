## 측정에 근거한 핵심 판단

1. **복잡도가 높을수록 기록 통합이 일반 MLP보다 더 유리해진다는 전반적 경향은 확인하지 못했습니다.** D−기본 A의 크기별 IoU 차이는 8×8에서 +0.08732, 12×12에서 +0.04755, 16×16에서 +0.01443으로 오히려 줄었습니다. 거리 구간별 차이도 Easy +0.11072, Medium +0.04435, Hard +0.00943, Extreme +0.03337로 단조 증가하지 않았습니다. 크기와 거리는 별개 축이며 아래 교차 표를 함께 봐야 합니다.
2. **출력 MLP를 붙인 효과는 전체 평균에서 관측됐지만 모든 난이도에서 좋아지지는 않았습니다.** C의 최종 IoU 0.51189는 B의 0.43793보다 높습니다. 반면 Easy에서는 C 0.51061보다 B 0.60774가 높았습니다. Easy는 최대 거리가8 이하라 R8=R_final이지만 B는 원래 R1~R8 중간 목표만 학습한 모델입니다. C/D의 이득에는 최종 영역 감독·원본 입력 직접 사용·추가 파라미터·추가 훈련이 함께 포함되므로 헤드 구조 하나만의 효과로 단정하지 않습니다.
3. **전체 과거 기록의 추가 이익은 작고 조건부였습니다.** D−C의 전체 평균은 +0.00083(약0.083 percentage point), paired seed 표준편차0.00295이며 3seed 중1개에서만 전체 IoU가 높았습니다. Hard +0.00303, Extreme +0.00465는 각3seed 모두 양수였지만 절대 이득은 작습니다. 16×16 Hard에서는 D−C가 약−0.00129였고, 모든 크기·난이도에 걸친 일관된 우위는 아닙니다. n=3과 단일 고정 데이터 생성기의 결과로 통계적 유의성이나 일반적 우위를 확정하지 않습니다.
4. **학습된 D는 기록에 의존했지만, 이것과 전체 과거 기록의 추가 가치는 구분해야 합니다.** D 0.51272에서 전체 기록 제거 시0.01186, 역순0.05301, 다른 샘플 전체 기록0.22756, R8 복제0.41497로 낮아졌습니다. 특히 R8만 제거하면0.08076으로 낮아졌고, R1~R4를 각각 제거했을 때는 오히려 평균 IoU가 조금 높아졌습니다. 초기 기록이 불필요하거나 해롭다는 원인을 확정할 수는 없습니다. 교란은 분포 밖 입력이고 재학습한 C는0.51189로 D와 거의 같으므로, D에 R8만 넣어 성능이 떨어졌다는 사실만으로 전체 기록이 마지막 상태보다 우수하다고 말할 수 없습니다.
5. **전체 IoU에서는 파라미터·선형 FLOPs 대조 후에도 D의 소폭 이득이 남았지만, 실제 효율 우위는 없었습니다.** D 0.51272 대 A_large 0.47420, A_flops 0.48280입니다. 그러나 Hard/Extreme에서 D는0.49589/0.40537, A_flops는0.52005/0.42624였으며 어려운 구간에서는 대조군이 더 높았습니다. 16×16 전체도 D 0.37980 대 A_flops 0.39678입니다. 평균 시스템 학습시간은 D 77.28초(코어 포함, 캐시 별도) 대 A_flops 14.91초, batch128 모델 실행 지연은 D 1.197ms 대 A_flops 0.146ms로 각각 약5.2배·8.2배였습니다. 같은 선형 연산 수가 같은 실제 비용을 뜻하지 않습니다.
6. **“단순한 문제에서는 차이가 없고 어려운 문제에서만 효과가 생긴다”는 결과는 아닙니다.** D−A의 차이는 Easy에서도 컸습니다. D−C에 한정하면 Hard/Extreme의 작은 양의 차이는 후속 확인할 신호지만, 크기별 교차 결과·seed 변동·넓은 단일 MLP 대조군을 포함하면 복잡한 문제에서 기록 통합의 우위가 입증됐다고 할 수 없습니다.

IoU만으로 성공을 판단해서도 안 됩니다. D의 전체 미로 완전 해결률은 약0.76%로 낮고, BCE는 D 0.52940 대 C 0.48875·기본 A 0.36316이었습니다. 이 실험의 결과는 부분 영역 품질의 차이이며 신뢰할 수 있는 일반 미로 해결 알고리즘을 완성했다는 뜻이 아닙니다.
