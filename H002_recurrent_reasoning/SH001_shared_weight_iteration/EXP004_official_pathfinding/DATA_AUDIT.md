# EXP004 — 본 실험 전 공식 데이터 감사

**Moving AI 공식 MAPF 지도·시나리오에서 추출한 단일 에이전트 경로 탐색 평가**를 위한 부분집합입니다. 공식 MAPF의 다중 에이전트 점수나 별도 단일 에이전트 평가 순위와 동일하지 않습니다.

공식 출처: [지도·시나리오 다운로드](https://movingai.com/benchmarks/mapf/index.html), [MAPF 설명·인용·라이선스](https://movingai.com/benchmarks/mapf.html), [지도·시나리오 형식](https://movingai.com/benchmarks/formats.html), [그리드 벤치마크](https://movingai.com/benchmarks/grids.html).

자료 표기: Open Data Commons Attribution License(공식 안내). 인용: Stern et al., *Multi-Agent Pathfinding: Definitions, Variants, and Benchmarks*, SoCS 2019, pp.151–158.

## 확보한 원본과 실제 형식

maze-32-32-2, maze-32-32-4, random-32-32-10, random-32-32-20, room-32-32-4의 원본 map ZIP5개와 even/random 시나리오 ZIP10개를 공식 서버에서 직접 받았습니다. 지도마다 각 유형25개, 총250개 시나리오 파일입니다. 자체 생성 지도를 섞거나 부족한 S/G 문제를 새로 만들지 않았습니다.

실제 지도는 `type octile`, height32/width32/map 헤더이며 문자 `.`·`@`와 random-32-32-20의 `T`가 관측됐습니다. `@`/`T`는 막힌 셀입니다. 파서는 `.`, `G`, `S`를 통행 지형으로 처리하고 `G/S`를 좌표 표식으로 읽지 않습니다. 지원하지 않는 물 지형 등은 조용히 변환하지 않고 오류를 냅니다.

실제 `.scen`은 `version 1`과 9개의 필드입니다: bucket, 지도명, width, height, sx, sy, gx, gy, 원본 비용. 원본 비용은 별도 구현한 sqrt(2) 대각선·코너 통과 금지 Dijkstra와 일치했고 최대 차이는 약1.22e-8이었습니다. 이번 과제의 정답은 이 값을 재사용하지 않고 **상하좌우4방향·각 비용1**로 다시 계산했습니다. 원점은 좌상단(0,0), x=열/y=행이며 입력·경로·그림 모두 같은 좌표를 사용합니다.

원본 URL, 실제 응답 URL, 다운로드 UTC시각, ZIP 및 내부 파일 SHA-256은 루트 `data/movingai_exp004/download_manifest.json`에 있습니다. 원본은 `raw/`에서 덮어쓰지 않습니다. 준비 데이터 식별자는 `3e4d5629b9fe7e71`입니다.

## 필터 결과

| 분류 | 행 수 |
|---|---:|
| 원본·파싱 성공 | 67,765 |
| 파싱 실패 | 0 |
| S=G 제외 | 50 |
| 4방향 최단 거리12 미만 제외 | 9,782 |
| 동일 지도/S/G 중복 제외 | 5,417 |
| 최종 적격 | **52,516** |

필터 우선순위에 따른 상호 배타적인 사유입니다. 좌표 범위·막힌 S/G·연결 불가로 제외된 문제는 없었습니다. 최소12 조건은 완화하지 않았습니다. 공식 원본의 제외 행도 그대로 남겨 두고 `row_ledger.jsonl`에 사유와 원본 ZIP/member/line/좌표를 기록했습니다. 3,879개 지도·G 거리장 전체를 BFS와 독립4방향 Dijkstra로 대조했습니다.

## 고정 분할

| 평가 범위 | 문제 수 | 실제 최단 거리 min / mean / max |
|---|---:|---|
| 학습 | 25,548 | 12 / 38.43 / 140 |
| 검증 | 3,208 | 12 / 37.22 / 141 |
| 동일 지도 새 목표 테스트 | 3,227 | 12 / 39.07 / 134 |
| 미관찰 지도 테스트 | 20,533 | 12 / 38.42 / 107 |

maze-32-32-4와 random-32-32-20은 지도 전체를 학습·검증에서 제외합니다. 다른3개 지도의 목표 지점을 seed42로80/10/10% 분할합니다. 거리장 전체를 감독하면 같은 지도·G의 정답은 S와 무관하게 같으므로, 단순 S/G 행 분리보다 엄격하게 **지도·G 단위**로 나누었습니다. 원본의 같은 목표 거리장 정답이 분할 사이에 중복되지 않습니다. S와 G는 모든 모델에 실제로 입력합니다.

거리 구간은 훈련 거리의 nearest 사분위수21/31/46에서 고정했습니다. Q1=12~21, Q2=22~31, Q3=32~46, Q4≥47입니다. 테스트로 구간을 조정하지 않았습니다.
