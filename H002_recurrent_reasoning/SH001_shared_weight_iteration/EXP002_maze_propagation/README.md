# EXP002 — 미로의 반복 추론

공유 MLP가 반복할수록 더 먼 도달 영역을 계산하는지, 원본 지도·목표의 보존과 중간 과정 감독을 구분하여 관찰합니다. 모델에 BFS나 격자 탐색 규칙은 삽입하지 않습니다.

## 실행

이 EXP002 디렉터리에서 PowerShell로 실행합니다.

```powershell
$env:PYTHONNOUSERSITE='1'
& D:\anaconda3\envs\research\python.exe -u src/train.py
```

단일 명령으로 데이터 생성·감사 → 3seed×4방식×80epoch 학습 → 테스트 1~32회 평가·지연 측정 → 독립 검증 → 그림·한국어 보고서를 생성합니다. 사전 파이프라인 확인은 `--smoke`(128/64/64, seed42, 2epoch)이며 본 실험과 구분합니다. CUDA 미지원 시 PyTorch/CUDA 빌드가 담긴 오류를 내며, 의도적인 CPU 실행만 `--device cpu`를 사용합니다. 사용자 패키지를 막기 위해 `PYTHONNOUSERSITE=1`을 검사합니다.

```powershell
& D:\anaconda3\envs\research\python.exe src/verify.py results/<run_id>
& D:\anaconda3\envs\research\python.exe src/visualize.py results/<run_id>
```

재검증은 별도 `verification_recheck.json`에 기록합니다. 시각화 명령은 파생 그래프·집계·보고서를 재생성합니다. 학습 실행은 timestamp와 UUID의 고유 ID를 사용하고 기존 실행을 덮어쓰지 않습니다. 실패 시 `failure.json`, 학습 중 실패라면 해당 모델의 실패 체크포인트와 이력도 남깁니다. 알고리즘이나 설정을 자동 교체하지 않습니다.

## 비교 조건

모든 모델은 **동일한 192→256→192 MLP**, ReLU/Sigmoid, 명목상 파라미터 98,752개입니다. 초기 입력은 `[W, G, G]`, R 예측은 출력 마지막 64차원입니다.

| 방식 | 다음 단계 입력 | 학습 목표 |
|---|---|---|
| A | 평가 시에만 전체 출력을 재입력 | 1회 R과 R_final의 BCE |
| B | 전체 192차원 출력 | 8회 R과 R_final의 BCE |
| C | 원본 W/G + 직전 출력 R | 8회 R과 R_final의 BCE |
| D | 원본 W/G + 직전 출력 R | 1~8회 각각 R_k의 BCE 평균 |

A는 기본 단일 단계 MLP 기준선입니다. A를 여러 번 평가하는 것은 학습하지 않은 사용 방식입니다. D의 R8 목표와 A/B/C의 R_final 목표는 다릅니다. 최종 영역 품질과 BFS 단계 재현을 별개 지표로 평가합니다.

같은 seed 42/123/2026에서는 데이터·초기 가중치·전체 epoch 배치 순서가 일치하며 두 해시를 체크포인트에 보존합니다. AdamW lr=0.001, weight_decay=0.01, batch128, 80epoch, FP32, TF32 비활성, deterministic algorithms, 전체 BPTT를 사용합니다. 각 모델 2,560 optimizer step이지만 B/C/D의 코어 호출은 20,480회로 A의 8배입니다. 마지막 epoch를 사용하고 검증/테스트로 체크포인트를 선택하지 않습니다. Validation은 관찰용이며 D의 표시 validation objective는 마지막 R8 BCE입니다(훈련 목적함수는 전체 8단계 평균).

A/C/D의 W/G 출력 헤드에는 손실 gradient가 없고 loss에 연결된 파라미터는 65,856개입니다. B에서는 중간 W/G 출력이 다음 입력이므로 역할이 다릅니다. 미사용 헤드도 AdamW의 weight decay로 값이 변할 수 있습니다. 명목상 파라미터 수 일치가 유효한 역할까지 일치함을 뜻하지 않습니다.

## 데이터와 난이도 감사

- 데이터 seed42, train4096 / val1024 / test1024. S는 모델 입력에 포함하지 않습니다.
- 절반은 분리 장벽을 둔 무작위 지도, 절반은 위쪽 3×4 coarse-grid DFS 통로와 분리된 아래쪽 방을 결합한 지도입니다. 회전·반사를 무작위 적용합니다.
- G는 임의로 고른 열린 칸의 연결 성분에서 먼 끝점으로 선택합니다. BFS eccentricity≥8, 분리된 빈칸≥6 및 전체 빈칸의≥20%를 요구합니다. 생성 예산을 초과하면 명시적으로 실패합니다.
- 회전·반사로 같아지는 벽 지도까지 중복 제거하고 전체 고유 풀을 셔플한 뒤 분할합니다. G/S만 바꿔 같은 지도를 다른 split에 넣지 않습니다.
- split마다 도달 가능한 S와 불가능한 S를 50:50으로 구성합니다. 가능한 S의 거리는 max(8, ceil(0.6×eccentricity)) 이상입니다.
- 학습 전에 모든 split에서 eccentricity>8 비율≥20%, >16 비율≥5%를 검사합니다. 벽 밀도, G 도달 영역, 가능한 S 최단 경로, 생성 계열의 분포와 전체 히스토그램을 `dataset_audit.json`에 보존합니다.
- 모든 빈칸 출력 기준선은 분리 영역 오탐률이 100%이며, IoU≤0.8입니다. 모든 셀 0 출력의 픽셀 오류율도 기록합니다. 픽셀 오류만 보고 성공을 판단하지 않습니다.

`dataset.npz`의 split별 walls, goal, distances, start, family와 `generation.json`이 생성 기록입니다. BFS 거리 -1은 도달 불가이며, 거리 0은 G입니다. `R_k=(0≤distance≤k)`, `R_final=(distance≥0)`로 모든 단계 정답을 정확히 복원할 수 있습니다. 공용 MNIST 데이터는 변경하지 않습니다.

## 지표와 그림

2026-10-23 기본 설정의 3seed×4방식 실험을 완료했습니다. [실제 결과·연구 질문별 답변](REPORT.md)을 참고하십시오. C는 1→8회 품질 개선과 32회 유지, D는 부분적인 전파·추가 확장을 보였지만 기본 MLP A의 1회 성능을 넘지는 못했습니다. 본 실행의 사후 검증 정밀도 수정과 원본 실패 기록도 보고서에 명시했습니다.

매 단계 final BCE·macro IoU/F1·전체 지도 정확도, R_k BCE·IoU·픽셀오류, S 정확도·도달 recall·불가 specificity, 분리된 빈칸 FPR·도달 영역 FNR·벽 FPR을 저장합니다. 단순 픽셀 정확도로 성능을 순위화하지 않습니다.

직전 단계 대비 신규 발견·올바른/잘못된 확장·제거·면적 감소, R_k보다 이른 도달 영역, 유효 전체 상태와 R 변화량, 고정점·2주기, 엔트로피(nats/cell), 고확신 오답을 기록합니다. C/D의 유효 상태는 원본 W/G+출력 R이며 무시되는 raw W/G 출력과 별개입니다. B/A의 반복 입력 W/G MAE는 원본 정보의 변화량입니다. 이 수치만으로 정보의 인과적 소실을 확정할 수 없습니다.

1~32회 전체 곡선과 선택 1/2/4/8/16/32회 표를 생성합니다. 그림에는 개별 seed와 평균±표본 표준편차가 표시됩니다. 샘플은 첫 seed의 개선·실패·2주기·잘못된 고정점·미수렴·최장 경로 조건에서 선택하여 네 모델 모두 같은 인덱스를 사용합니다. 해당 유형이 관측되지 않으면 selection에 null을 기록합니다. 벽=짙은 회색, 올바른 발견=초록, 오탐=빨강, 누락=노랑, G=파란 원, S=자홍 별입니다. `BFS R8`도 final 기준 누락을 표시하여 목표 차이를 드러냅니다.

GPU 시간은 테스트 앞 128개의 동일 배치, 단계별 warm-up3회 후10회 측정이며 CUDA 동기화를 포함합니다. 모델 전용은 입력 장치 전송을 제외하고, 종단 간은 W/G 입력과 마지막 192차원 출력 전송을 포함합니다. 1~32회 평균·표준편차를 보존합니다. 선형층 FLOPs는 sample당 `196608×반복수`이며 multiply-add=2입니다. bias·활성화·cat·역전파·optimizer 비용은 포함하지 않는 추정입니다.

## 검증과 보존

수작업 미로·대각선 금지·Manhattan 거리로 BFS를 검증하고, 전체 데이터의 R_k/R_final을 별도 동기식 flood-fill 구현과 대조합니다. 98,752개 파라미터의 동일 객체 재사용, 모든 중간 R gradient, C/D 문맥 고정, 추론 가중치 불변, 유한 상태·손실, seed 재생성, split 중복, 초기 가중치·배치 순서 해시를 검사합니다. 모든 체크포인트를 재로딩하여 전체 출력과 지표를 재현하고 torch로 독립 BCE·IoU·픽셀오류를 대조합니다.

기존 H001 전체, H002 EXP001 전체, 공용 data의 파일 목록·SHA-256을 실행 전후 비교합니다. 원래 실행 소스와 해시를 보존합니다. `checkpoints/<run_id>/`와 `results/<run_id>/`는 기존 `.gitignore`에 따라 로컬 산출물로 관리합니다. Git에서 관리하는 별도 `REPORT.md`에는 실제 결과와 여섯 연구 질문에 대한 해석을 남깁니다.

생성 분포·지도 크기·끝점 선택의 편향이 있으며, D의 성공도 중간 과정 지도학습을 뜻합니다. 자율적 사고의 증거로 해석하지 않습니다.
